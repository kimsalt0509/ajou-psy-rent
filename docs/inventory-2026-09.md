## 0. Cursor에게: 작업 방식

1. **코드는 수정하지 마세요.** 기존 데이터 구조(`lib/types.ts`의 `Item`, `StorageItem`)를 그대로 씁니다.
2. 아래 표의 데이터를 등록하는 **일회성 스크립트** `scripts/seed-inventory.mjs`를 만드세요.
   - `.env.local`의 `FIREBASE_*` 값으로 `firebase-admin` 초기화 (기존 `scripts/test-late-return-email.mjs`의 env 파싱 방식 참고)
   - **기본 실행은 미리보기(dry-run)**: 무엇을 추가/수정할지 표로 출력만 하고 실제로 쓰지 않음
   - `--apply` 옵션을 줬을 때만 실제로 씀
3. **이름(name)으로 기존 문서와 매칭**해서 있으면 수정, 없으면 추가하세요. 같은 이름을 새로 만들어 중복시키지 마세요.
4. **절대 하지 말 것**
   - `rentals` 컬렉션 수정·삭제 (대여 기록)
   - 이 문서에 없는 기존 물품 삭제 (목록만 출력해서 알려주기)
   - 기존 물품의 `dueDays`(대여 기간) 변경 — 이 문서에 값이 있을 때만 변경
   - 충전기·볼펜·멀티탭 등 과방 비치 비품을 `items`(대여 물품)에 만드는 것 — 모두 `storage`(창고)에만 등록
   - 창고에 같은 이름 두 줄 만들기 — 장소가 달라도 한 줄로 합산
5. 실행 후 결과(추가 n개, 수정 n개, 건너뜀 n개)를 출력하세요.

### ⚠ 재고 수량 계산 규칙 (중요)

사이트의 "남은 수량" = `total` − (반납 안 된 대여 수량 합)

- **일반 대여품** (반납하는 물건): `total` = 보유 개수 그대로
  - 이미 대여 중인 수량보다 작게 줄이면 안 됨 (예: 우산은 현재 1개 대여 중)
- **소모품** (`consumable: true`, 반납 안 함): 소모품 대여는 영원히 "반납 안 됨"으로 남기 때문에
  **`total` = 목표 남은 수량 + 지금까지 대여된 수량 합** 으로 넣어야 화면에 목표 수량이 보입니다.
  - 예: 인공눈물은 현재 total 10, 대여 3 → 남은 수량을 30으로 만들려면 **total = 33**
  - 스크립트에서 해당 물품의 `returnedAt == null` 대여 수량을 조회해서 자동 계산하세요.

## 1. 원본 해석 규칙

- 원본 표의 **현황 칸이 `N`** → **보유 개수**가 실제 수량
- **현황 칸이 숫자** → **현황**이 실제 수량 (보유 개수는 참고용)
- 현황이 `-`이거나 빈칸 → 수량 미확인 (아래 "확인 필요"에 정리)

## 2. 대여 물품 (`items` 컬렉션) — 학생이 사이트에서 빌리는 것

### 2-1. 반납하는 물품 (`consumable: false`)

> 충전기 등 과방에 두고 쓰는 비품은 대여 물품이 아니라 **창고**에 등록합니다 (3번 참고).

| 이름 | 이모지 | total | note (학생에게 보임) | 기존 문서 | 근거 |
|---|---|---|---|---|---|
| 우산 | ☔ | 9 | 사용 후 까먹지 말고 반납 | 있음 (현재 6 → 9) | 보유 9, 현황 N |
| 돗자리 | 🧺 | 2 | 큰 거 1개, 작은 거 1개 | 있음 (현재 3 → 2) | 보유 2, 현황 N |
| 렌즈통 | 👓 | 3 | 사용 후 약품통에 다시 넣어주세요 | 없음 → 추가 | 현황 3 / "대여 가능, 사용 후 다시 가져다 둘 것" |

### 2-2. 소모품 (`consumable: true`) — 가져가서 쓰는 것

| 이름 | 이모지 | 목표 남은 수량 | note (학생에게 보임) | 기존 문서 | 근거 |
|---|---|---|---|---|---|
| 인공눈물 | 👁️ | 30 | 약품통 (A4책장 옆 책장) | 있음 (total 10·대여 3 → total 33) | 현황 30 |
| 밴드 (일반) | 🩹 | 44 | 약품통 (A4책장 옆 책장) | 없음 → 추가 | 현황 "일반 44" |
| 밴드 (작은 것) | 🩹 | 4 | 약품통 (A4책장 옆 책장) | 없음 → 추가 | 현황 "작 4" |
| 면봉 | 🧴 | 19 | 약품통 (개별포장) | 없음 → 추가 | 현황 19 |
| 생리대 | 🌸 | 6 | 약품통 (A4책장 옆 책장) | 없음 → 추가 | 현황 6 (보유 16) |
| 타이레놀 | 💊 | 0 | 약품통 · 소진 시 학생회에 알려주세요 | 없음 → 추가 | 현황 0 (1통 총 10알) |

> 새로 추가하는 소모품은 대여 기록이 없으므로 total = 목표 남은 수량 그대로입니다.

## 4. 관리자 참고 (사이트 등록과 무관, 운영 규칙)

- 필통의 볼펜·보드마카는 2개 이상 있는지 수시 확인. 부서지거나 다 쓰면 창고에서 꺼내 **심리학과 이름 스티커**를 붙여 넣기
- 볼펜·보드마카·가위는 **한 달에 한 번** 반드시 확인
- 렌즈통·탈지면은 다 쓰면 **보충하지 않음**
- 타이레놀·인공눈물·연고는 다 쓰면 **구매 담당자**에게 연락 (구매 주기 확인 후 보충)
- 면봉: 약품통에 **개별포장 10개**가 유지되도록 창고에서 보충. 개별포장을 다 쓰면 500개입을 통째로 약품통에 넣고, 그것도 다 쓰면 구매 담당자에게 연락
- 밴드: 약품통 밴드를 다 쓰면 창고의 **110매입 밴드통**을 통째로 약품통에 넣기. 그것도 다 쓰면 구매 담당자에게 연락
- 물티슈·휴지: **매달 첫 주에 한 번만** 보충 (다 썼다고 바로 보충하지 않기). 창고까지 다 쓰면 연락
- 스테이플러심: 매달 한 번 체크, 다 쓰면 채우고 심 재고가 떨어지면 연락
- 박스테이프·볼펜·스테이플러심 재고를 다 쓰면 연락
- 창고(재고칸)는 담요로 덮어 둔 책장 칸. 사라진 물품 없는지 체크하고, 꺼내 쓸 때 **사이트 창고 탭 수량도 같이 수정**
- 우산·돗자리는 추가 구비 계획 없음
- 충전기는 사용 후 A4용지 선반 위에 정리되어 있는지 확인

## 5. 등록 전 확인 필요 (사람이 결정할 것)

1. **창고 수량 미기재 항목** (스테이플러심, 집게, 클립, 탈지면, 이름표 스티커, 생리대, 재고칸 가위) — 수량을 세서 채우거나, 0으로 등록 후 나중에 수정
   - 필통 볼펜은 원본에서 "너무 많아서 세지 않음"이라 재고칸 18개만 셌음
2. **창고 볼펜 "6(+12)"** — 18개로 해석함. 다르면 수정
3. **타이레놀 현황 0** — "다 썼음"으로 해석함. 아직 있다면 수량 수정
4. **밴드 창고 110매입 1통** — 원본 재고물품 표에는 없고 전달사항에만 있어서 추가함
5. **대여 기간(dueDays)** — 원본에 없어서 설정 안 함. 우산 등에 기한을 두려면 관리 탭에서 따로 입력
